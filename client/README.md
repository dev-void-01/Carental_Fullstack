# Car Rental Client

The client is a React application built with Vite. It uses the Car Rental API provided by the `server` directory.

## Run locally

1. Start the server by following [server setup](../server/README.md).
2. Create `.env` in this directory using `.env.example` as a template. Set `VITE_BASE_URL=http://localhost:3000`.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

Open the URL printed by Vite (usually `http://localhost:5173`).

## Client commands

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint

For project overview and complete startup instructions, see the [root README](../README.md).
